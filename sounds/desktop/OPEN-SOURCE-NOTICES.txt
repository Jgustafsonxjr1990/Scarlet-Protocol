Scarlet Protocol Sound Studio

Application and build source are included alongside the executable in desktop/sound_studio.py, desktop/build_studio.py and sound_backend.py. All synthesized audio is original and released under CC0-1.0.

The portable executable includes CPython 3.12.14 (PSF license), Qt/PySide6 6.8.3 (LGPL-3.0, unmodified runtime libraries), and the PyInstaller 6.22.3 bootloader (GPL-2.0 with its bundling exception). See LICENSES for terms.

Runtime sources and notices:
https://www.python.org/downloads/source/
https://download.qt.io/archive/qt/6.8/6.8.3/
https://code.qt.io/pyside/pyside-setup.git/
https://github.com/pyinstaller/pyinstaller

Rebuilding: from the extracted sound-theme folder, install PySide6-Essentials==6.8.3 and pyinstaller==6.22.3 into a Python environment, then run python3 desktop/build_studio.py. The artwork and application code can be edited; the payload checksum is regenerated by the build. Substitute compatible Qt/PySide runtime libraries by rebuilding.
