# Scarlet Protocol motion suite

Three optional per-user KWin effects are bundled with the complete theme:

- **Pulse:** open/close with a narrow red sweep and short perimeter flash.
- **Recall:** minimize/restore folds toward the task manager icon.
- **Overdrive:** maximize/restore expands with a segmented scarlet scan.

Run `bash motion-suite/install.sh` from the extracted Global Theme folder.
Then enable each in **System Settings → Window Management → Desktop Effects**.
Choose Pulse for open/close, Recall for minimize, and Overdrive for maximize;
turn off any overlapping built-in motion effects. They are never enabled by
the Global Theme installer. The three GIFs here are illustrative previews.

This suite is included unchanged from the separate Scarlet Protocol animation
packages. It has been checked locally for source and shader validity, but
the exact motion on your KWin session must be inspected after installation.
