# Scarlet Protocol reactive effects — 3.0

The bundled Glitch Drag and Phase Relay scripts now match the focused 3.0 packages. For independent installation, use `bash install.sh drag` or `bash install.sh focus` from the repository root. See `effects/glitch-drag/README.md` and `effects/phase-relay/README.md` for design, settings and verification.

The compatibility installer in this folder still installs both effects together. Prefer the focused installers, which verify loading and have rollback support. Older combined previews and regression fixtures describe earlier versions; current tests live in the two focused packages.
